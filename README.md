# LLM ControlCenter

여러 대의 LLM 백엔드를 하나의 클러스터로 묶고, 누가 무엇을 쓰는지 관제하며,
나가는 프롬프트에서 개인정보·민감정보를 걸러내는 **설치형 솔루션**입니다.

한 번 설치하면 **여러 조직(테넌트)** 을 함께 수용합니다.

---

## 30초 데모 — GPU 없이

```sh
pip install -e .
python -m app --demo
```

목 프로바이더로 뜨므로 **GPU 도 실제 노드도 필요 없습니다.** 콘솔에 관제 UI 주소와
시드 테넌트 2개의 토큰이 찍힙니다.

목으로 시연되는 것:

| 보여줄 것 | 방법 |
|---|---|
| 테넌시 격리 | 테넌트 2개가 서로의 작업을 조회할 수 없다 |
| **가드 1단(패턴)** | PII 샘플 투입 → 마스킹·차단. **LLM 불필요** |
| **출력 마스킹** | 목 노드의 `reply` 를 PII 로 지정하면 응답이 가려지는 것을 확인 |
| **시크릿 탐지** | API 키·개인키를 프롬프트에 넣어 마스킹 확인. 자기 서비스 토큰도 잡힙니다 |
| 배치 라우팅 | 가짜 노드 여러 대 → 티어 우선순위·데이터 경계 |
| **장애 폴백** | 노드를 내리면 다른 노드로 넘어간다 — 클러스터 제품의 핵심 데모 |
| 비용 예약/정산 | 가짜 단가로 예산 소진 → 무료 경로 강등 |
| 관제 UI 전체 · 알림 | 노드 그리드·큐·사용량·감사·웹훅 |

목으로 **안 되는 것**: 실제 생성 품질, 가드 2단 LLM 분류(설계상 내부 노드 전용).
2단까지 보여주려면 소형 모델(1.5b급, ~1GB) 하나를 로컬에 얹으세요.

### 노드도 토큰도 없이 통합 코드 작성

```sh
python clients/mock_server.py --config config &
LCC_URL=http://localhost:8610 LCC_TOKEN=any python clients/client.py "요약할 내용"
```

목 서버는 **역할 목록을 실제 설정에서 읽습니다** — 손으로 적으면 진짜 서버와
역할 이름이 어긋나고, 어긋난 채로 통합이 끝나면 배포 당일에 404 를 만납니다.

## 설치

```sh
tar xzf llm-controlcenter-<ver>.tgz && cd llm-controlcenter
./preflight.sh                 # 포트·디스크·메모리·도커 — 실패 사유를 사람 말로
docker compose up -d
docker compose logs controlcenter
```

마지막 줄이 중요합니다. **최초 기동 값이 로그에 한 번만 찍힙니다.**

- 마스터 KEK — **백업과 다른 곳에** 보관하세요. 잃으면 기존 암호문은 영구히 못 엽니다.
- 플랫폼 관리자 토큰 · 첫 테넌트의 관리자/서비스 토큰

**기본 자격증명은 존재하지 않습니다.** 전부 무작위로 생성되고 한 번만 표시됩니다.

### 도입 첫날에 막히지 않습니다

베이스라인 가드 규칙은 **유예 모드**로 시작합니다 — 차단(`block`) 등급이 마스킹(`full`)
으로 낮춰져 요청을 세우지 않습니다. 처음부터 차단으로 켜면 도입 첫날 프로덕션이 서고,
그러면 설치처는 규칙을 통째로 꺼버립니다. **안 켜진 필터는 없는 필터입니다.**

`audit`(통과 + 기록)이 아니라 `full`(마스킹)인 것이 중요합니다. `audit` 로 내리면
유예 기간 내내 주민번호가 **마스킹 없이** 노드로 나갑니다 — 개인정보를 거르려고 산
제품이 도입 첫 주에 정확히 그것을 안 하는 셈입니다. 탐지 기록은 두 등급이 동일하므로
오탐률 측정과 승격 게이트는 그대로 작동합니다.

며칠 오탐률을 본 뒤 관제 UI 에서 유예를 해제하세요. 유예 중에는 화면·API·`doctor`
가 그 사실을 계속 알립니다 — **조용한 유예가 더 나쁘기 때문입니다.**

## 서버는 몇 대인가

**컨트롤 플레인은 1대입니다** (Demo · Starter · Standard). 그 1대에 컨테이너가 돕니다.

| 흔히 필요한 것 | 이 설계 | 왜 |
|---|---|---|
| 노드 에이전트 서버 | 없음 | 엔드포인트 등록형 — **노드에 아무것도 설치하지 않습니다** |
| 별도 웹서버 | 없음 | 관제 UI 를 앱이 직접 서빙 |
| 메시지 브로커 | 없음 | 잡 큐가 DB 테이블 |
| 캐시 서버 | 없음 | 헬스·모델 인벤토리는 프로세스 메모리 |
| 워커 서버 | 없음 | 추론은 전부 LLM 노드에서 |

**서버는 아니지만 별도 위치가 필요한 것 둘**: ① 백업 저장소 ② 마스터 KEK.
둘을 컨트롤 플레인 호스트에 함께 두면 1대 구성의 단순함이 그대로 단일 실패점이 되고,
백업이 유출되면 암호문도 함께 열립니다.

### 프로파일별 권장 사양

| | Demo | Starter | Standard | Scale |
|---|---|---|---|---|
| vCPU / RAM | **1 / 512 MB** | 2 / 4 GB | 4 / 8 GB | 4×N / 8 GB |
| DB | SQLite | SQLite | SQLite 또는 PG | Postgres |
| 디스크 | 2 GB | 50 GB | 100~200 GB | 별도 볼륨 |
| LLM 노드 | 목 (+선택 1.5b) | 내장 1 (16~24 GB) | 2~3 (24~48 GB) | 4+ |

컨트롤 플레인은 **추론하지 않습니다** — asyncio I/O 와 DB 뿐이라 가볍습니다.
라즈베리파이급에서도 돕니다.

### 데모 노트북

**Xubuntu 24.04 LTS 권장.** Windows·macOS 는 Docker Desktop 이 VM 으로 ~2GB 를
먼저 먹습니다 — 컨트롤 플레인(512MB)보다 도커가 4배 무겁습니다. Linux 는 네이티브라
오버헤드가 거의 0 이고, 그래서 `python -m app --demo` 네이티브 경로도 함께 제공합니다.

데모 준비 체크리스트:

| # | 항목 | 왜 |
|---|---|---|
| 1 | **절전·뚜껑 닫힘 억제** | 시연 중 뚜껑을 닫으면 노드가 죽습니다 |
| 2 | 부팅 시 자동 기동 | `restart: unless-stopped`. 현장에서 전원만 켜면 뜨게 |
| 3 | zram 스왑 | 4GB 에서 모델 로드 시 결정적 |
| 4 | mDNS(`*.local`) | 데모 현장 네트워크가 매번 바뀝니다 |
| 5 | **디스크 암호화(LUKS)** | 암호화된 프롬프트와 **마스터 KEK 를 같은 디스크에** 들고 다닙니다 |

5번은 데모라서 넘어갈 항목이 아닙니다. 제품 문서가 "KEK 는 백업과 분리" 를 요구하면서
데모 관행이 그 반대면, 설치처가 따라 하는 것은 관행 쪽입니다.

## 통합

역할 이름이 계약이고 **모델은 정책입니다.** 소비자는 모델명을 하드코딩하지 않습니다.

```sh
curl -X POST https://llm.example.com/v1/generate \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"role":"summarize","prompt":"요약할 내용","end_user":"u_8f3a91","wait":30}'
```

계약은 **서비스가 직접 서빙합니다** — 정적 문서가 아니라 토큰마다 생성됩니다.

| 엔드포인트 | 내용 |
|---|---|
| `GET /v1/integration` | 사람이 읽는 통합 가이드 |
| `GET /v1/meta` | 기계가 읽는 계약 — 역할·한도·오류 코드 |
| `GET /v1/openapi.json` | OpenAPI 3.1. `role` enum 에 **이 토큰이 쓸 수 있는 역할만** |
| `GET /v1/client/*` | 단일 파일 클라이언트 + 목 서버 원본 |
| `GET /healthz` | 인증 불필요 |

### 오류 처리

**분기는 HTTP 상태와 `retryable` 로 합니다.** `message` 로 분기하지 마세요 —
로케일에 따라 바뀌므로 한국어로 분기한 코드는 영어 환경에서 조용히 실패합니다.

```json
{"code": "rate_limited", "message": "요청 한도를 초과했습니다 (tenant 단위, 60회/분).",
 "retryable": true, "scope": "tenant", "limit": 60}
```

`429` 의 `scope` 는 **어느 단계**(tenant · service · end_user)에서 걸렸는지 알려줍니다.
자기 서비스 한도를 올려도 안 풀리는 이유가 테넌트 총량인 경우가 있기 때문입니다.

### `wait` 를 쓰세요

`wait` 초까지 기다렸다가 못 끝나면 `status: "pending"` 으로 돌려줍니다.
**응답 모양이 완료든 대기든 같으므로 호출자 코드에 분기가 필요 없습니다.**

폴링해야 하면 서버가 준 `retry_after` 를 지키세요. 고정 간격 폴링은 큐가 길어질수록
관제 서버를 때리고, 그 서버는 자기 부하가 아니라 **클러스터 포화의 증상으로** 죽습니다.
완료 콜백(웹훅)은 제공하지 않습니다.

## 운영

```sh
./doctor.sh                # 설정·스키마·키·유예 모드
./doctor.sh --probe        # 노드 도달성까지
./doctor.sh --bundle       # 지원 요청용 번들 (비밀은 마스킹됨)
./backup.sh /mnt/nas/llmcc # prompt_cipher 를 제외하고 백업
./restore.sh <백업.tgz>    # 스키마 호환 검사 + 오버라이드 되돌림 경고
./bundle.sh                # 에어갭 번들
```

- **메트릭**: `GET /metrics` (Prometheus/OpenMetrics). 설치처의 기존 모니터링에 물립니다.
  **테넌트 이름은 라벨에 없습니다** — 전체가 보는 대시보드에 테넌트별 소비량이 뜨면
  그것도 정보 유출입니다.
- **로그**: 구조화 JSON stdout. **프롬프트·응답 본문·비밀 미포함.**
- **알림**: 웹훅(Slack/Teams 호환) + SMTP. `LCC_NOTIFY_WEBHOOK` · `LCC_SMTP_*`.
  **상태 전이에서만** 보내고, 실패가 파이프라인을 죽이지 않습니다.

### 백업과 복원

백업에는 **`prompt_cipher` 가 들어가지 않습니다.** 7일 뒤 암호문을 지워도 30일 전
백업을 복원하면 지워졌어야 할 원문이 되살아나기 때문입니다.

가장 강한 삭제는 **테넌트 DEK 폐기(crypto-shredding)** 입니다 — 백업에 암호문이
남아 있어도 복호화가 불가능해집니다.

**마스터 KEK 는 백업에 담기지 않습니다.** 따로, 다른 곳에 보관하세요.

## 에어갭

```sh
./bundle.sh                       # 인터넷 되는 곳에서 만들고
docker load -i image.tar          # 설치처에서 풀고
LCC_AIRGAP=1 docker compose up -d
```

에어갭 모드에서는 **경계 밖(external) 노드가 배치 단계에서 차단되고** 등록도 거부되며,
관제 UI 가 그 사실을 상시 표시합니다. 설정에 남아 있는데 조용히 실패하는 것이 최악입니다.

## 열어두는 부채

제품이 **하지 않는 것**을 적어 둡니다. 안 적으면 설치처가 한다고 믿습니다.
각 항목의 판정과 해제 조건은 [docs/design-decisions.md](docs/design-decisions.md) 에 있습니다.

### 아직 없는 것 — 하기로 했지만 미구현

"하지 않기로 한 것" 과 섞지 않습니다. 섞으면 미구현이 설계 결정으로 위장됩니다.

| 항목 | 지금 상태 |
|---|---|
| **출력 검사가 1단뿐** | 응답도 마스킹·봉인·보존·열람 감사를 거치지만, 2단(LLM) 맥락 분류는 입력에만 있습니다. 응답마다 추론이 한 번 더 늘어나므로 지연·비용을 실측한 뒤 붙입니다 |
| **시크릿 탐지가 접두사·문맥 기반** | 벤더 접두사가 없고 대입 문맥도 없는 자격증명(맨몸 랜덤 문자열)은 못 잡습니다. 엔트로피 탐지는 실측 결과 진짜 시크릿과 UUID·git SHA 를 가르지 못해 기각했습니다 |
| **인젝션 탐지가 휴리스틱** | 공개 탈옥 구문 패턴이라 새로운 표현은 놓칩니다. 구조적 방어(울타리·카나리아)는 표현과 무관하게 도는 반면, 이 팩은 아는 문장만 잡습니다. 경량 전용 분류기는 후속 |
| **다중 워커의 슬롯 예약이 프로세스 로컬** | 동기 경로 두 곳(`/v1/embed`·가드 2단)이 API 워커에서 배치합니다. 워커 N 개면 그 두 경로의 노드 동시성이 최대 N 배까지 초과될 수 있습니다. `tests/test_multiprocess.py` 가 이 한계를 실행 가능한 형태로 못박습니다 |
| **관리 신원은 토큰뿐** | IdP(OIDC/SAML)·MFA·관리 세션 만료가 없습니다. 관리자의 퇴사는 IdP 에서 일어나는데 이 제품의 토큰은 거기 이어질 길이 없습니다 |
| **멱등성이 페이로드를 비교하지 않는다** | 같은 `Idempotency-Key` 로 *다른* 프롬프트를 보내면 첫 요청의 잡이 돌아옵니다. 키가 작업을 식별합니다 — 요청마다 새 키를 쓰고 재시도할 때만 재사용하세요. `/v1/embed` 는 아직 대상이 아닙니다 |
| **감사 로그에 변조 증적이 없다** | 보존(365일)은 하지만 해시 체인·외부 내보내기는 없습니다 |
| **토큰 상한이 없다** | 무료 경로는 달러가 0 이라 200KB 프롬프트 1건과 1KB 1건이 레이트리밋에서 같은 1건입니다. 처리율은 `/metrics` 와 관제 API 에 띄우지만 **한도로 걸지는 않았습니다** — 설치처의 분포를 모르는 채 건 한도는 꺼집니다 |

### 하지 않기로 한 것

| 항목 | 근거 |
|---|---|
| Starter·Standard 는 컨트롤 플레인 SPOF | 의도한 선택. Scale 프로파일에서 해소 |
| **클라우드 API 키가 플랫폼 단위** | 노드가 공유 자원이라 노드 1개 = 키 1개입니다. 대가: 프로바이더 청구서 상 귀속과 키 폐기 단위가 플랫폼입니다. 테넌트별로 가르려면 `tenant_affinity` 전용 노드 |
| **데이터 경계는 2값 고정** | `internal`/`external` 만. "EU 리전만"·"국내 IDC 만" 을 표현할 수 없습니다. 일반화 경로는 architecture.md §13 |
| **서버가 프롬프트를 재작성하지 않는다** | "프롬프트는 호출자 소유" 계약. 서버는 해시로 드리프트를 **감지**만 합니다 |
| **응답 캐시 없음** | 캐시는 테넌트 간 응답 누출이라는 새 격리 면을 만듭니다. 격리가 최대 리스크인데 절감을 위해 누출 면을 늘리지 않습니다 |
| 이중 실행을 *막지는* 못한다 | 노드에도 클라우드에도 취소 의미론이 없다. `needs_review` 로 **드러낼** 뿐 |
| `data_boundary` 는 선언을 믿는다 | 노드가 실제로 어디 있는지 검증하지 않는다 |
| 필터가 100% 가 아니다 | 패턴은 오탐/미탐이 있고 LLM 분류는 **측정 대상**이다. `audit` 등급이 그 측정 장치 |
| 실패 잡의 미보고 토큰 과소 계상 | 끊긴 추론의 소비 토큰을 프로바이더가 주지 않는다 |
| 노드 간 모델 자동 복제 없음 | 용량 판단은 사람 몫. 단일 호밍 경고로 **드러내기만** |
| 스트리밍·완료 콜백 없음 | 아웃바운드는 인증·SSRF 문제를 만든다 |
| 테넌트 간 노드 공유의 잔여 위험 | 공유 노드에서 모델 keep-alive 가 테넌트를 넘나든다. 강한 격리가 필요하면 `tenant_affinity` 전용 노드 |
| 노드 구간을 네트워크로 신뢰한다 | Ollama 가 기본 무인증. `internal` 노드는 사설망 전제이고 그 전제를 문서·preflight 로만 강제한다 |
| 가드 정답셋의 품질이 곧 측정의 품질 | 번들 기본 세트는 출발점일 뿐. 설치처가 자기 도메인 샘플을 안 넣으면 오탐률 숫자가 의미를 잃는다 |
| 처리량 수치는 추정 | 부하 테스트 전까지 사실로 취급하지 않는다 |
| 라이선싱·버전 정책 | 이번 범위 제외(프로토타입). 스키마 버전은 마이그레이션 안전장치로 남긴다 |

## 개발

```sh
python -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/pytest -q        # 실제 노드·클라우드 키 없이 전부 통과
```

의존성은 5개입니다: `starlette` · `uvicorn` · `httpx` · `PyYAML` · `cryptography`.
마지막 하나는 의식적인 추가입니다 — **암호를 직접 구현하는 쪽이 훨씬 나쁩니다.**
