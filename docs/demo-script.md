# 발표 시연 대본 — 15분

**발표 주제: 설치형 LLM 통합 관제 센터, LLM ControlCenter의 설계와 구축** (2026-10-28 채택)

발표 자리에서 **화면을 어떤 순서로, 무슨 말과 함께** 보여 줄지 적어 둔다. 제품 설명은
[README](../README.md) 와 [feature-spec](feature-spec.md) 이 하고, 이 문서는 당일의 손발이다.
짝이 되는 스크립트는 [examples/showcase/showcase.py](../examples/showcase/showcase.py) — 같은 장면을
API 로 돌리고, `--seed N` 으로 대시보드를 채운다.

준비물: 관제 UI 로그인 — 플랫폼 관리자 계정 하나로 된다(0.7.5). 개요·테넌트·노드·모델은 그대로, 규칙·가드·작업·감사·사용량은 테넌트 묶음
머리의 「볼 테넌트」에서 시연 테넌트를 골라 본다(그 사실이 그 테넌트의 감사에 「플랫폼 열람」으로 남는다 — 감사 장면에서 보여 줄 수 있다).
0.7.4 이하에서는 이 탭들이 로그인한 테넌트의 것이라 **시연 테넌트의 관리자 토큰 또는 계정**이 따로 필요했다 · 클라이언트 페이지 사용자 계정 ·
서비스 토큰과 테넌트 관리자 토큰(스크립트용, 환경 변수로) · 노트북에 저장소 체크아웃(비상용 로컬 데모).

## 1. 전날 점검

| 확인 | 어떻게 | 안 되면 |
|---|---|---|
| 노드가 건강한가 | 개요 탭 「노드 n / n」 · `GET /v1/status` 의 `nodes.healthy` | 노드 탭에서 마지막 오류를 보고, 프로바이더(Ollama)가 그 주소로 열려 있는지 노드 기계에서 확인 |
| 대시보드에 데이터가 있는가 | 개요 탭 추이 · 사용량 탭 표 | `showcase.py --seed 30 --pace 1` 로 채운다(30건이면 10분 안팎, 노드 속도에 따라 다름) |
| 가드 유예 모드 | 헤더의 「가드 유예」 필 · 규칙·가드 탭의 설정 | **발표 전에 정한다.** 번들 베이스라인의 패턴 규칙에는 차단이 없어 켜져 있어도 장면의 판정은 같지만, 빨간 필과 배너가 내내 보이고 규칙 표에서 번들의 유일한 `block`(2단 규칙 `undisclosed_financials` 의 경계 밖)이 `full` 로 낮춰져 보인다 — 끄거나, 켜진 채로 "도입 첫 주의 안전장치" 라고 설명 |
| 계정 로그인 | 관제 UI `admin` · 클라이언트 페이지 사용자 계정으로 각각 로그인 | 비밀번호를 모르면 플랫폼 관리자가 계정 탭에서 재설정 |
| 테넌트 관리자 탭 | 두 번째 브라우저 탭에서 시연 테넌트의 관리자 토큰으로 「토큰으로 접속」 — 사용량·작업·규칙·가드가 **그 테넌트의 것**으로 채워져 보이는가 | 토큰이 없으면 플랫폼 관리자가 계정 탭에서 `tenant_admin` 계정을 만들어 그 계정으로 로그인 |
| 스크립트 예행 | `showcase.py --only 2,3,4` 를 실제 호스트에 | 장면 3 에서 **카드번호**가 마스킹본에 남으면 로케일 팩(ko_KR)이 꺼진 것 — 테넌트 로케일 확인(이메일은 베이스라인이 `audit` 라 남는 것이 맞다) |
| 공개 주소 | 발표장 네트워크에서 `https://…/ui/` 와 `/client/` 가 열리는가 · 인증서 경고 없음 | LAN 주소나 테일넷 주소를 예비로 적어 둔다 |
| 브라우저 | 확대 110~125% · 라이트 테마(프로젝터) · 알림·확장 끄기 · 탭 둘(관제 · 클라이언트) 미리 로그인 | — |
| 비상용 로컬 데모 | `python -m app serve --demo` 가 뜨고 배너의 admin 으로 들어가지는가 | `.venv` 재생성(`pip install -e .`) |
| 실가동 트래픽 | 전날부터 **전용 서비스**(예: `demo-traffic`, 허용 역할은 요약·분류·대화·임베딩)로 업무 시간 곡선의 요청을 실제 노드에 흘려 둔다 — 개요의 24시간 추이·작업·사용량이 실제 처리로 채워지고, 사용량의 서비스 축에서 실제 사용과 갈라 보인다. 배경 잡은 한 번에 하나만 띄워 노드 한 칸을 시연자 몫으로 남긴다 | **32B 로 갈 수 있는 역할(분석)은 넣지 않는다.** 2026-11-02 첫 설치처에서 32B 가 올라가자 7B·14B 가 메모리에서 밀려나 같이 들어간 요청이 수십 초 밀렸다. 7B·14B·임베딩만이면 셋이 함께 올라가 있어 1~3초 |

## 2. 당일 10분 전

1. `/healthz` 200 · 개요 탭 노드 건강 · 큐 0 · 승인 대기 0(있으면 승인하거나 그대로 설명할 준비).
2. 클라이언트 페이지 요청 탭에서 요약 한 번 — 첫 요청은 모델 로딩으로 느릴 수 있다. **이 한 번이 워밍업이다.** 실가동 트래픽이 돌고 있으면 7B·14B 는 이미 올라가 있다.
3. 규칙·가드 탭 → 가드 미리보기에 아무 문장이나 넣어 응답이 오는지.
4. 플러그인 유닛(있다면)은 끈 채로 — 발표 중 2분마다 잡이 생기면 기록 탭이 어지럽다.

## 4. 비상 계획

| 상황 | 대응 |
|---|---|
| 노드가 죽었다(개요 탭 노드 0 / 1) | 생성 장면은 건너뛰고 **미리 적재한 기록·추이**로 설명한다. 가드 미리보기(장면 6·7)는 노드 없이 돈다. 남은 시간이 있으면 노트북의 로컬 데모(`serve --demo`)로 전환 — 목 프로바이더라 답변 품질 대신 흐름을 보여 준다 |
| 첫 요청이 30초 넘게 걸린다 | 모델 로딩이다. 워밍업을 빠뜨린 것 — 기다리는 동안 가드 칩·기록 탭을 먼저 보여 준다 |
| 장문 분석(32B) 뒤 요청이 느리다 | 32B 가 올라가며 7B·14B 를 메모리에서 내렸다 — 다시 올라오기까지 몇 요청이 느리다. **32B 장면(배치 레인)은 맨 마지막에 두거나 건너뛴다.** 분석 역할은 스마트 라우팅이라 짧은 질의는 7B, 여러 문서를 가로지르는 장문은 32B 로 간다 |
| 공개 주소가 안 열린다 | LAN 주소 / 테일넷 주소로. 인증서 경고가 뜨는 주소는 발표에 쓰지 않는다 |
| 로그인이 안 된다 | 「토큰으로 접속」 — 테넌트 관리자 토큰으로 콘솔에 들어간다(플랫폼 탭은 안 보인다). 5회 실패 시 15분 잠금이니 비밀번호를 거듭 틀리지 말 것 |
| 가드가 안 잡는다 | 테넌트 로케일이 `ko-KR` 인지(로케일 팩 `ko_KR`), 미리보기의 「걸린 규칙」 표로 확인. 숫자만 덩그러니 넣은 샘플은 체크섬을 통과해야 걸린다 — 아무 숫자나 안 걸린다. **카드는 예외(0.7.2)** — "카드번호 2222-2222-0222-2222" 처럼 카드라는 말 바로 뒤에 오면 체크섬이 틀려도 `credit_card:context` 로 가린다(청중이 아무 번호나 불러도 이 형태면 잡힌다). 2020-10 이후 부여된 주민등록번호는 검증식이 성립하지 않아 `kr_rrn:unverified`(audit)로만 잡힌다 — 샘플은 `990101-1234563` 처럼 검증식을 지나는 값으로 |
| 클라이언트 페이지에 「요청」 탭이 비어 있다 | 플랫폼 계정(`admin`)이나 플랫폼 테넌트에 만든 사용자 계정은 역할이 빈 콘솔 서비스에 묶여 요청을 못 보낸다 — 화면이 그 이유를 말한다(0.7.3). 클라이언트 시연은 **테넌트의 사용자 계정**(`default` 테넌트의 `hosub`, 또는 시험 테넌트 `test` 의 `test1`)으로. 역할 카드를 줄이려면 콘솔에서 그 서비스의 허용 역할을 고친다 |
| "왜 차단이 안 되나" 라는 질문 | 베이스라인의 패턴 규칙은 가리기만 한다(번들의 `block` 은 경계 밖을 향한 2단 규칙 `undisclosed_financials` 하나뿐) — 그 밖의 차단은 설치처가 오탐률을 재고 승격하는 것이 설계다(README 부채 표 · GUARD-12). 미리보기의 등급 표를 가리키며 답한다 |
| 화면이 비어 보인다 | 공개 진입점이 플랫폼 면을 막았으면 배너가 이유를 말한다 — 테넌트 탭 대신 사용량·규칙 탭으로 간다 |

## 5. 예상 질문

| 질문 | 답 |
|---|---|
| 스트리밍은 왜 없나 | 출력 가드와 함께 풀어야 한다 — 가드를 지나지 않은 텍스트가 실시간으로 나가면 안 된다. 보류이고 해제 조건은 interactive 레인 테넌트의 요구(G7) |
| 기존 OpenAI SDK 를 그대로 쓸 수 있나 | 지금은 아니다. 채택했으나 보류 — 요구한 설치처가 생기면 `model` 자리에 역할 이름을 받는 `/v1/chat/completions` 를 `Pipeline.chat` 위에 형식 변환으로 얹는다(G6). 대신 SDK 한 파일과 목 서버가 있다 |
| SSO·MFA 는 | 관리 신원은 로컬 계정뿐이다(AUTH-8 미구현). 퇴사 처리는 계정 정지와 토큰 폐기로 사람이 한다 |
| 클라우드 모델도 되나 | 된다 — 노드의 `data_boundary` 가 `external` 이면 가드가 그 경계용 마스킹본을 따로 만들고, 차단 등급이면 그쪽으로는 안 간다. 키는 플랫폼 단위다(테넌트별 키는 미구현) |
| 가드는 100% 인가 | 아니다. 패턴은 오탐·미탐이 있고 2단 LLM 분류는 측정 대상이다 — 그래서 `audit` 등급, 오탐 검토 큐, 승격 게이트가 있다 |
| 감사 로그는 못 고치나 | 해시 체인이 조작을 **드러낸다**(`doctor` 가 지목). 막지는 못한다 — DB 쓰기 권한자의 전체 재계산은 외부로 내보낸 사본과 대조할 때만 걸린다 |
| 프롬프트 원문은 저장되나 | 저장소에는 마스킹본만. 원문은 테넌트 DEK 로 암호화한 금고에 두고, 열람은 단건 API + 감사다. 키를 잃으면 원문은 영구히 못 연다 |
| 프롬프트 감사 자료는 어디서 보나 | 테넌트 관리자 콘솔의 「감사」(0.7.4) — 관리 감사 기록("원문 열람" 필터로 누가 가리기 전 프롬프트를 봤는지)과 가드 탐지 전체 이력. 가린 본·답변은 「작업」, 제출용 사본은 설정 → 데이터 관리 → 내보내기(JSON 하나에 작업·사용량·탐지·감사) |
| 테넌트별 예산·요청 한도·가드는 어디서 정하나 | 한도(0.7.6): 플랫폼 관리자가 설정 → 연결 정보 맨 위 「테넌트 한도」, 또는 플랫폼 「테넌트」 표의 「한도」 — 테넌트 관리자에게는 읽기 전용이다(자기 한도를 올릴 수 있으면 한도가 아니다). 서비스별 한도는 그 아래 서비스 편집이고 둘 다 걸린다. 예산 0 은 "유료 경로 금지" 다. 가드: 「가드」 탭 규칙 표의 「등급 올리기」 · 「규칙 추가」 · 「이 테넌트가 더하거나 올린 규칙」(지우면 기본 등급으로). 가리기는 바로 저장되고 차단(`block`)은 오탐 검토 기준을 넘어야 저장된다 |
| 규모는 | 컨트롤 플레인 1대(Starter·Standard 는 의도된 SPOF). 노드는 등록형으로 늘리고, 용량 산정은 capacity.md 의 측정값 기준 |
| 비용은 어떻게 세나 | 역할·모델·노드별 단가표로 예약 후 정산. 내부 노드는 0 이라 **건수**로만 잡힌다 — 토큰 상한은 분포를 본 뒤 건다 |

## 6. 스크립트

```bash
# 장면 전부 (1~9). 9 는 테넌트 관리자 토큰이 있을 때만
LCC_TOKEN=... LCC_ADMIN_TOKEN=... python examples/showcase/showcase.py --url https://llmcc.example

# 일부만
python examples/showcase/showcase.py --url https://llmcc.example --token "$LCC_TOKEN" --only 3,4

# 대시보드 채우기 — 30건, 1초 간격. 노드 속도에 따라 5~15분
python examples/showcase/showcase.py --url https://llmcc.example --token "$LCC_TOKEN" --seed 30 --pace 1
```

장면 3 의 마스킹본, 장면 4 의 차단(또는 유예 모드 안내), 장면 9 의 추이 스파크라인은 발표 중 터미널을 띄워
보여 줘도 된다 — 화면보다 "API 로도 같은 것이 보인다" 를 말할 때 효과가 있다.

## 7. 첫 설치처 메모 (2026-10)

- 공개 주소는 hosub 의 Caddy 를 지나고, 이 사이트는 운영자 결정으로 플랫폼 면(`/v1/platform/*`)을 열어 두었다
  ([release-checklist](release-checklist.md) 0.6.0 행). 테넌트 탭이 공개 주소에서도 보인다.
- 노드는 `macstudio` 하나(Ollama · qwen2.5 7b/14b/32b · bge-m3). 한 노드라 단일 호밍 경고가 역할 수만큼 뜬다 —
  "자동 복제를 안 하니 사람이 본다" 로 설명한다.
- 0.6.1 업그레이드 때 doctor 가 **가드 유예 모드가 켜져 있다**고 알렸고, 2026-10-21 운영자 요청으로 **껐다**
  (`POST /v1/platform/guard/grace-mode` `{"enabled": false}` · doctor 통과, 알림 0건). 헤더의 빨간 필과 배너는 사라졌다.
  베이스라인의 패턴 규칙에는 block 이 없으므로 장면의 판정은 그대로고, 번들의 유일한 block(2단 규칙 `undisclosed_financials` 의
  경계 밖)은 이제 실제로 막으며, 승격한 차단 규칙이 생기면 그것도 막는다.
- 예제 플러그인 유닛(hosub)은 정지 상태다. 플러그인 탭에는 설치본이 남아 있어 보여 줄 수 있다.
